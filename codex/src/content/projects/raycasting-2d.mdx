# Raycasting 2D Engine

Motor de renderização estilo Wolfenstein 3D implementado do zero. Simula
projeção 3D em ambiente 2D com texturas e colisão.

## Detalhes técnicos
- **Algoritmo:** DDA (Digital Differential Analyzer) para raycasting
- **Texturas:** mapeamento de coordenadas de parede (wall-X)
- **Colisão:** AABB + sliding collision
- **Mapa:** grid 2D com tipos de parede variados
- **Performance:** 60 FPS em 640×480 (Canvas 2D)
