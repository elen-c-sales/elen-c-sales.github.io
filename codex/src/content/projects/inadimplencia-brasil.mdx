# Inadimplência no Brasil

Dashboard interativo desenvolvido em **R + Shiny** para analisar a evolução da
**inadimplência das pessoas físicas no Brasil** ao longo do tempo, com dados
oficiais do **Banco Central do Brasil** coletados automaticamente via API.

## Funcionalidades

- Série temporal interativa da inadimplência.
- Filtros de período dinâmicos.
- Análise de variações mensais em valores absolutos e percentuais.
- Estatísticas descritivas: mínimo, máximo, média, mediana e desvio padrão.
- Cards de resumo com os principais indicadores do período selecionado.
- Tabela dinâmica com os dados filtrados.

## Stack

- **R + Shiny** — aplicação reativa.
- **Shinydashboard** — layout e interface.
- **Plotly** — gráficos interativos.
- **DT** — tabelas dinâmicas.
- **tidyverse** — manipulação e transformação dos dados.
- **rbcb** — coleta dos dados via API do Banco Central.

## Dados

- **Inadimplência das Pessoas Físicas no Brasil**
- Fonte: Banco Central do Brasil
- Consulta automática via API com o pacote `rbcb`

## Como rodar localmente

```r
install.packages(c("shiny", "shinydashboard", "tidyverse", "plotly", "DT", "rbcb"))
shiny::runApp("Caminho/para/a/pasta/inadimplencia-shiny-dashboard")
```
