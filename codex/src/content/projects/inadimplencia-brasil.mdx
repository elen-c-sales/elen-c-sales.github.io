# Inadimplência no Brasil

Dashboard interativo analisando dados do Banco Central do Brasil com visualizações
dinâmicas e séries temporais. Permite explorar a evolução da inadimplência por
modalidade de crédito, região e período.

## Detalhes técnicos
- **Framework:** R Shiny + bslib (Bootstrap 5)
- **Visualização:** Plotly (interativo) + ggplot2 (estático)
- **Dados:** API SGS/BCB (Sistema Gerenciador de Séries Temporais)
- **Deploy:** shinyapps.io

## Features
- Filtros dinâmicos por ano, modalidade, segmento
- Séries temporais com zoom/pan
- Decomposição sazonal (STL)
- Exportação de dados filtrados (CSV)
