# PyOpenCV FaceRec

Sistema completo de reconhecimento facial com OpenCV (LBPH). Inclui Interface
Gráfica moderna (CustomTkinter), cadastro automático e reconhecimento em tempo real.

## Detalhes técnicos
- **Algoritmo:** LBPH (Local Binary Patterns Histograms) — robusto a variações de iluminação
- **Interface:** CustomTkinter (tema escuro/claro, responsiva)
- **Cadastro:** captura automática de múltiplos ângulos via webcam
- **Reconhecimento:** tempo real com threshold configurável
- **Persistência:** modelo salvo em XML + labels em JSON
