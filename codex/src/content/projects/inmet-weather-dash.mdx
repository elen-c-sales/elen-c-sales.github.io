# INMET Weather Dash

Pipeline completo de dados: Coleta automática (Scraping), processamento e
visualização em tempo real.

## Detalhes técnicos
- **Coleta:** Selenium (headless) — scraping INMET (estações automáticas)
- **Processamento:** Pandas — limpeza, interpolação, agregação horária/diária
- **Visualização:** Dash + Plotly — mapa interativo, séries temporais, alertas
- **Deploy:** Docker + systemd timer (coleta a cada hora)
- **Alertas:** thresholds configuráveis (temp, chuva, vento)
