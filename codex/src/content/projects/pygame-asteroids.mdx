# Pygame Asteroids

Uma interpretação moderna do clássico jogo de arcade Asteroids da Atari,
apresentando um sistema visual de profundidade 3D exclusivo que utiliza
interpolação de cores e rolagem parallax.

## Detalhes técnicos
- **Motor:** Pygame 2
- **Profundidade 3D:** interpolação de cores baseada em distância + parallax multi-camadas
- **Física:** Newtoniana simplificada (aceleração, atrito, wraparound)
- **Partículas:** explosões, trails, screen shake
- **Web port:** via pygbag (WebAssembly)
