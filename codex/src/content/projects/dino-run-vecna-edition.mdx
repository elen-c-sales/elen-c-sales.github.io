# Dino Run Vecna Edition

Endless runner desenvolvido em **Python + Pygame**, com adaptação temática de
*Stranger Things*: o antagonista **Vecna**, **Demobats** e o ambiente do **Mundo
Invertido**. O objetivo é percorrer a maior distância possível evitando
obstáculos, com dificuldade progressiva.

O jogo também roda direto no navegador, compilado para **WebAssembly com
Pygbag** e hospedado no GitHub Pages.

## Mecânicas e funcionalidades

- **Geração procedural de obstáculos** — vinhas, relógios e demobats aparecem
  aleatoriamente.
- **Sistema de pontuação** — a pontuação cresce com a progressão e o recorde
  (*high score*) é persistido localmente em `highscore.txt`.
- **Colisão** — hitboxes ajustadas para detecção precisa entre o personagem e os
  obstáculos.
- **Efeitos visuais** — partículas de cinzas flutuantes do Mundo Invertido e
  **parallax em duas camadas** (15% e 40% da velocidade do jogo), criando
  profundidade no cenário.
- **Trilha sonora** — música temática de Stranger Things em loop contínuo.

## Controles

- **Barra de Espaço** ou **Seta para Cima** — pular
- **Seta para Baixo** — agachar (para esquivar de obstáculos aéreos)
- **Barra de Espaço** ou **R** — reiniciar após o game over

## Estrutura

- `dino-run.py` — loop do jogo, classes e lógica de controle.
- `assets/` — sprites, camadas de parallax, efeitos sonoros e trilha.
- `demo/` — vídeo de demonstração.
- `highscore.txt` — recorde persistido.
- `LICENSE` — licença MIT.

## Como rodar

Requisitos: Python 3.x e Pygame.

```bash
pip install pygame
python dino-run.py
```

## Versão web

A versão web é gerada com Pygbag:

```bash
pip install pygbag
pygbag --build .
# copie build/web para docs/ e publique no GitHub Pages
```

O deploy usa a branch `main`, pasta `/docs`. Instruções completas em
`DEPLOY.md`. A versão web compartilha o mesmo código do desktop e adiciona
`async/await` para compatibilidade com o navegador.

## Origem

O projeto nasceu como estudo de Pygame e acabou inspirando outros projetos do
portfólio, como o **Pygame Asteroids** — que, por sua vez, partiu de uma
visualização de campo estelar feita por outra desenvolvedora no LinkedIn.
