# Dino Run Vecna Edition

Versão temática do Dino Run onde você enfrenta o Vecna. Um jogo endless
runner divertido desenvolvido para web.

## Detalhes técnicos
- **Motor:** JavaScript vanilla + HTML5 Canvas
- **Obstáculos:** Vecna + minions gerados proceduralmente
- **Power-ups:** escudos, multiplicadores, slow-motion
- **Persistência:** high score em localStorage
- **Deploy:** GitHub Pages
