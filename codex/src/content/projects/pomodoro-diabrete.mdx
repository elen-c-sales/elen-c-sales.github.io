# Pomodoro Diabrete

Um timer Pomodoro diferente: um **monstrengo pixel** que acompanha sua sessão.
Durante o foco ele vai cansando (animação de exaustão); quando a pausa começa,
ele se transforma num **diabrete alegre** e recupera energia numa janela overlay
transparente — você *precisa* clicar pra iniciar a pausa, o que quebra o
autopiloto.

## Detalhes técnicos
- **Motor:** Pygame 2 + spritesheet 16×16 (Aseprite)
- **Estado:** máquina de estados simples (foco → transição → pausa → recuperação)
- **Overlay:** janela `pygame.NOFRAME` com `SRCALPHA` + `pygame.display.set_mode`
- **Persistência:** JSON local (ciclos, tempo total, humor do bicho)

> **Segredo:** o Diabrete vive no rodapé do códice. Clique nele 5 vezes.
