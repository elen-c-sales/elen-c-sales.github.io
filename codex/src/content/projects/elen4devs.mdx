# Elen4Devs — Suíte de Ferramentas Dev

Aplicação web estática com **15 ferramentas** para o dia a dia de quem
desenvolve: manipulação de texto, calculadoras matemáticas, cálculos de datas e
utilitários de validação. Todo o processamento acontece no navegador — nenhum
dado sai da máquina do usuário e não existe backend.

O projeto foi reescrito do zero em **Astro 6 + React 18 + TypeScript**, com
catálogo central de rotas, busca por command palette e testes automatizados.

## Ferramentas incluídas

### Texto & Strings (7)
- **Remover linhas duplicadas** — mantém a primeira ocorrência, com opção de
  diferenciar ou ignorar maiúsculas e minúsculas.
- **Ordenar linhas** — alfabética crescente (A-Z) e decrescente (Z-A), com
  suporte a acentuação em português.
- **Localizar & substituir** — substituição em massa com Expressões Regulares
  e modo case-insensitive.
- **Prefixo & sufixo por linha** — insere caracteres no início e no fim de cada
  linha, com opção para ignorar linhas vazias.
- **Conversor de caixa** — MAIÚSCULAS, minúsculas, Title Case, camelCase,
  snake_case e kebab-case.
- **Inverter texto** — inverte caracteres e também de cabeça para baixo em
  Unicode.
- **Suíte completa** — contador de caracteres, palavras, linhas e tempo
  estimado de leitura.

### Matemática (3)
- **Porcentagem** — 6 modos de cálculo em tempo real, exibindo a fórmula usada.
- **Áreas geométricas** — círculo, quadrado, retângulo, triângulo, losango,
  trapézio e elipse, com diagrama SVG dinâmico e seleção de unidade.
- **Regra de 3** — proporções diretas e inversamente proporcionais.

### Datas (1)
- **Datas & dias úteis** — diferença entre datas (dias corridos, úteis e
  semanas) e soma/subtração de dias com opção de contar apenas dias úteis.

### Dev Tools (4)
- **CPF e CNPJ** — geradores e validadores por módulo 11, com ou sem pontuação.
- **Cartão de crédito (Luhn)** — geração de números para testes (Visa,
  Mastercard, Elo e Amex) e validação com detecção de bandeira.
- **JSON** — formatador e minificador.
- **UUID v4 e Base64** — geração de UUIDs em lote e codificação/decodificação
  Base64 em UTF-8.

## Experiência de uso e acessibilidade

- **Command Palette** (`Ctrl+K` / `Cmd+K`) para pular direto para qualquer
  ferramenta.
- **Filtro no hub inicial** por categoria e busca textual.
- **Favoritas e usadas recentemente** salvas em `localStorage`.
- **Links compartilháveis** — os cálculos podem ser reproduzidos via
  parâmetros na URL.
- **Tema claro e escuro** persistido localmente.
- Execução **100% client-side**, sem envio de dados.

## Stack e arquitetura

- **Astro 6** — páginas estáticas por rota, ilhas React para interatividade.
- **React 18 + TypeScript** — componentes das ferramentas e command palette.
- **Catálogo central** em `src/data/tools.ts` — rotas, palavras-chave e FAQs.
- **Lógica pura** em `src/lib/` — módulos de math, dates, dev e text testáveis
  sem interface.
- **Vitest** — testes unitários da lógica.
- **GitHub Actions** — `check`, `test`, `build` e deploy do `dist/` no GitHub
  Pages.

## Desenvolvimento local

Requisitos: Node.js 22 ou superior.

```bash
npm install
npm test
npm run check
npm run dev      # http://localhost:4321
npm run build    # gera ./dist
```

## Deploy

O workflow `.github/workflows/deploy.yml` executa `npm run check`, `npm test`,
`npm run build` e publica o diretório `dist/` no GitHub Pages a cada push.
