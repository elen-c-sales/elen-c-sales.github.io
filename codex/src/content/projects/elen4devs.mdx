# Elen4Devs — Utils Suite

Suíte web responsiva com calculadoras e ferramentas para devs. Foco total em
acessibilidade (ARIA) e performance.

## Ferramentas incluídas
- **Conversores:** base64, URL encoding, JSON formatter, color picker
- **Calculadoras:** regex tester, timestamp converter, hash generator
- **Utilitários:** lorem ipsum, UUID generator, JWT decoder

## Detalhes técnicos
- **Vanilla JS** (ES modules, sem dependências)
- **Acessibilidade:** ARIA labels, focus management, keyboard navigation, screen reader tested
- **CSS:** Custom properties, container queries, prefers-reduced-motion
- **Performance:** < 10KB gzipped, zero layout shift
- **Deploy:** GitHub Pages
