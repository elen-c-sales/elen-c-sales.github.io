# GUNSHIP CQB

Simulador tático de combate espacial 3D em primeira pessoa. Pilote uma corveta,
gerencie sistemas PDC automáticos e intercepte ameaças em combates de alta
letalidade.

## Detalhes técnicos
- **Render:** Pygame + OpenGL (pygame.gfxdraw + glDrawArrays)
- **Combate:** sistemas de armas baseados em prioridade de ameaça
- **HUD:** radar, gestão de energia, status de escudos/mísseis
- **Arquitetura:** ECS simples (entidade-componente-sistema) customizada

> **Segredo:** visite esta página no terminal com `open gunship-cqb`.
