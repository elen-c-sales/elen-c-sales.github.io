# GUNSHIP CQB

Simulador tático de combate em primeira pessoa inspirado em *The Expanse*.
Você pilota uma **canhoneira de classe corveta**, gerencia os sistemas de
defesa PDC e enfrenta combates espaciais de alta letalidade.

## Armamentos

- **CANNON** — arma principal de curta/média distância. Dispara rajadas de 10
  projéteis com detecção de colisão por **volume varrido** (*swept volume*),
  garantindo precisão em altas velocidades.
- **TORPEDO** — míssil teleguiado que exige **lock-on**. As naves inimigas têm
  lógica de evasão, com 10% de chance de escapar ao detectar um míssil.

## Defesa de ponto (PDC)

O sistema **PDC** (Point Defense Cannon) é automatizado e focado em interceptar
torpedos:

- Ao pressionar **ENTER**, busca e dispara contra ameaças próximas por 2
  segundos.
- Quando o HUD indica trava em um torpedo inimigo, **ENTER** executa um disparo
  de precisão direto no alvo.

## Dano e colisão

- Torpedos inimigos causam **80 de dano**; a nave do jogador tem **100 de
  integridade** total.
- O raio de colisão é **adaptativo**: se ajusta conforme a proximidade do alvo
  para evitar falhas de registro em combate próximo.

## Controles

| Tecla | Função |
| --- | --- |
| Setas / WASD | Controle de direção (pitch/yaw) |
| ESPAÇO | Disparo da arma selecionada |
| TAB | Alternar entre CANNON e TORPEDO |
| ENTER | Ativar defesa automática PDC / disparo em lock |
| R | Reiniciar a simulação após destruição |
| ESC | Sair |

## Como rodar

Requisitos: Python 3.10+ e Pygame 2.6.1+.

```bash
pip install pygame
python main.py
```
