# Youtube Audio Downloader

Uma interface simples para baixar áudios de vídeos do Youtube, construída com
Tkinter.

## Detalhes técnicos
- **GUI:** Tkinter (nativo, leve)
- **Backend:** yt-dlp (robusto, atualizado)
- **Formatos:** MP3, M4A, Opus (qualidade selecionável)
- **Features:** playlist support, metadata embedding, progress bar
- **Threading:** download não bloqueia UI
