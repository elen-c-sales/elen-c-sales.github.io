# ZenCalc Mobile

Calculadora minimalista com UX inspirada no ecossistema Apple. Design limpo e
responsividade nativa.

## Detalhes técnicos
- **Framework:** React Native + Expo (managed workflow)
- **UI:** StyleSheet + Animated API (60 FPS)
- **Estado:** useReducer + Context (sem Redux)
- **Persistência:** AsyncStorage (histórico, preferências)
- **Temas:** claro/escuro (system sync)
- **Build:** EAS Build → Play Store / TestFlight
